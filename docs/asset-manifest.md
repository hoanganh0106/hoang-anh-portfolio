# Active asset manifest

The active homepage ports the owner-selected Lovable design at https://hn-tech-journal.lovable.app/ .

- Identity and five domain modules: inline SVG geometry translated from the published reference into `LovableSystemMap.tsx`. No remote model, raster screenshot background or GPU renderer is required.
- Grid and cable lines: CSS and decorative SVG from the reference. Text and destinations remain real HTML links.
- IBM Plex Sans Latin: locally hosted WOFF2, variable weight 400–600, 45,712 bytes.
- IBM Plex Mono Latin: locally hosted WOFF2, weight 400 (14,708 bytes) and 500 (14,888 bytes).
- Font license: SIL Open Font License 1.1, copied to `web/public/fonts/IBM-Plex-OFL.txt` from Google Fonts' IBM Plex source. Total font payload is 75,308 bytes before HTTP transfer compression.
- Detail-page waveforms/pipelines: conceptual inline illustrations; no measured samples or private diagrams are published.

Earlier procedural Three.js scene files remain in the repository but are not imported by the active homepage. Their historical geometry counts are not performance measurements for this design.
